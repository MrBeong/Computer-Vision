# Computer Vision

**C++ · OpenCV · CMake**

컴퓨터비전 수업에서 제공된 C++·OpenCV 예제로 공부한 내용입니다.

| 학습 영역 | 예제에서 다룬 내용 |
| --- | --- |
| 이미지·영상 입출력 | 이미지 로드·저장, 카메라·영상 프레임 |
| 사용자 입력 | 키보드·마우스 이벤트와 영상 화면 |
| 명암과 분할 | 히스토그램, 평활화, 고정·적응형 임계처리 |
| 필터와 변화량 | blurring, image gradients |
| 특징과 매칭 | Hough transform, template matching |
| 영상 기하 | geometric transformations, hidden picture 실습 |
